## 1. 项目概述

### 1.1 背景
临床科研中常用商业软件 **Slice-O-Matic** 手工勾画腹部 CT 的皮下脂肪、内脏脂肪与骨骼肌，逐层计算面积/体积。手工勾画耗时、结果依赖操作者经验、难以复现。

本项目已完成一套**零依赖的阈值几何分割算法（v3）**，可对腹部 CT 轴位切片自动分割出：
**皮下脂肪（SAT）、内脏脂肪（VAT）、骨骼肌（SMA）**，并计算横截面积（cm²）。

### 1.2 目标
开发一款**单机桌面软件**，让非计算机专业的临床/科研人员能够：
1. 导入 DICOM 切片，正常显示；
2. **一键自动**画出三类组织的面积；
3. 在自动结果基础上**像 Slice-O-Matic 那样人工微调**（区域生长、画笔增删、擦除）；
4. 实时看到面积数值，并导出数据与图片。

### 1.3 范围（本期）
- **仅处理孤立单层轴位切片**（一个患者一张片），只计算**面积（cm²）**，不计算体积。
- 自动分割采用**阈值几何法（v3）**，不接入 AI 模型（nnU-Net 暂不在本期范围）。
- 界面语言：**简体中文**。

### 1.4 不在本期范围
- 完整多层序列的**体积（cm³）**计算；
- AI 深度模型分割；
- 测量工具（长度/角度/圆形 ROI）；
- 高级编辑：矩形/椭圆选区、魔棒、自由手绘轮廓/套索；
- 肌间脂肪单列（本期并入 VAT）；
- PACS/网络传输、多用户、账号权限；
- 3D 重建、放疗计划等专业功能。

## 2. 术语与约定

| 术语 | 含义 |
|---|---|
| HU | CT 值（Hounsfield Unit），经 `RescaleSlope/Intercept` 换算后的像素值 |
| SAT | 皮下脂肪 Subcutaneous Adipose Tissue，HU 约 −190 ~ −30 |
| VAT | 内脏脂肪 Visceral Adipose Tissue，HU 约 −190 ~ −30 |
| SMA | 骨骼肌面积 Skeletal Muscle Area，HU 约 −29 ~ +150 |
| 身体掩膜 | Body mask，体部区域（HU > −350 填洞后），用于限定分割范围 |
| 区域生长 | Region growing，从种子点出发按 HU 容差向邻域扩散的交互分割法 |
| cm² | 面积单位 = 像素数 × 像素面积(mm²) ÷ 100 |

## 3. 用户与使用场景

### 3.1 目标用户
临床/科研人员，具备影像判读能力，但**非计算机专业**；期望"开箱即用、界面友好"。

### 3.2 典型场景
1. **批量初筛**：导入一个含几十张 DICOM 的文件夹 → 一键自动分割 → 导出全部面积表。
2. **单例精修**：对某一张片，自动结果个别区域不准 → 用画笔/区域生长增删 → 面积实时更新 → 导出。
3. **复核与复现**：载入上次保存的工程文件，继续修改或核对，保证结果可复现。

## 5. 功能需求

### FR-1 数据导入
- **FR-1.1** 支持导入单个 `.dcm` 文件。
- **FR-1.2** 支持导入整个文件夹（递归识别 `.dcm`），列出全部病例供批量处理。
- **FR-1.3** 读取并展示关键 DICOM 信息：PatientID、检查/序列描述(ProtocolName)、层厚、像素间距(PixelSpacing)、窗宽窗位、是否增强。
- **FR-1.4** 对无法读取或缺失 PixelSpacing 的文件给出明确提示（该文件无法计算面积）。
- **FR-1.5** 校验不同厂商（GE/Siemens/Philips/联影）的 DICOM 均可正常解析。

### FR-2 图像显示与浏览
- **FR-2.1** 以灰度显示原始 CT，窗口自适应。
- **FR-2.2** 支持**窗宽/窗位（WW/WL）**调节：鼠标拖拽调节 + 预设（腹部软组织窗、骨窗、肺窗）。
- **FR-2.3** 支持**缩放**（滚轮）与**平移**（右键/中键拖拽）。
- **FR-2.4** 显示比例尺、当前光标处的 HU 值与坐标。
- **FR-2.5** （多层序列预留）若后续支持序列，提供层切换；本期单层可略。

### FR-3 自动分割（v3 算法）
- **FR-3.1** 一键对当前切片执行自动分割，生成 **SAT / VAT / SMA** 三个图层。
- **FR-3.2** 自动分割遵循 v3 算法（见 §9 算法说明），参数可在设置中调整（默认值见附录 A）。
- **FR-3.3** 分割在 **2 秒内**完成单张切片。
- **FR-3.4** 自动分割结果以半透明彩色叠加在 CT 上（便于核对）。
- **FR-3.5** 批量模式下，可对文件夹内全部病例一键自动分割。

### FR-4 交互式微调（核心功能，对标 Slice-O-Matic）
> 用户可在自动结果基础上**局部增加或减少**某类组织的面积。
> **本期仅提供两种编辑工具：区域生长 + 画笔（增/擦）。** 矩形/椭圆选区、魔棒、自由手绘轮廓不在本期范围（见 §1.4）。

- **FR-4.1 图层管理（互斥语义）**
  - 一个像素**只能属于一类**：背景 / SAT / VAT / SMA，三类**互斥**，各层面积不重复计算；
  - 编辑采用**覆盖语义**：向某层加像素时，自动把该处从其他层移除；擦除则回到背景；
  - 每层可：显示/隐藏、调整颜色、调整透明度、锁定（防误改）、清空。
- **FR-4.2 区域生长（Region Growing）** —— 对标 Slice-O-Matic 的种子点生长
  - 用户在图上点击**种子点**，算法从种子沿邻域向 HU 在容差范围内的像素扩散；
  - 参数：**HU 下限 / 上限**、**连通性**（4/8 邻域）、**是否限制在身体掩膜内**、**半径上限**；
  - **默认**限制在身体掩膜内并设半径上限，避免一次点出整片脏器（可调/可关）；
  - 支持**连续多颗种子**叠加生长；
  - 生长结果**加入目标层**（覆盖语义），也可作为"选择区"再被擦除。
- **FR-4.3 画笔工具**
  - **增加笔（画笔）**：按设定笔刷半径，涂抹加入当前目标层；
  - **擦除笔（橡皮）**：涂抹移除像素（回到背景）；
  - 笔刷半径可调；支持硬边/软边。
- **FR-4.4 撤销 / 重做**：所有编辑操作可撤销/重做（建议 ≥ 30 步），快捷键 Ctrl+Z / Ctrl+Y。
- **FR-4.5 实时刷新**：任何微调后，对应面积数值**立即更新**。
- **FR-4.6 视图辅助**：可开关"仅显示某层""只看叠加""半透明混合"等，便于核对边界。
- **FR-4.7** 人工修改仅作用于**该病例该切片**，不影响其他病例。

### FR-5 面积计算与显示
- **FR-5.1** 按像素面积换算：`面积(cm²) = 像素数 × (像素间距mm)² ÷ 100`。
- **FR-5.2** 实时显示三个组织的面积（cm²）。
- **FR-5.3** 显示派生指标：总脂肪面积、VAT/SAT 比值、肌肉平均 HU、身体面积等。
- **FR-5.4** 明确标注"自动分割值"与"人工微调后值"（或提供"重置为自动结果"按钮）。

### FR-6 结果导出
- **FR-6.1** 导出 **CSV / Excel**（含每例的面积与派生指标；批量时为多行表）；一并导出 DICOM 中的 **PatientID、性别(PatientSex)、年龄(PatientAge)**。
- **FR-6.2** 导出**叠加分割图**为 PNG（含颜色图例、面积数值）。
- **FR-6.3** （可选）导出分割掩膜为 NRRD/NIfTI，供其他软件使用。
- **FR-6.4** 编码：UTF-8 with BOM（Excel 中文不乱码）。

### FR-7 批量与工程/会话管理
- **FR-7.1** 批量导入后，**可在病例列表中逐例点入显示区进行人工精修**，各例的标注独立保存，互不影响。
- **FR-7.2** 可保存**工程文件**（记录：病例列表、每例的自动参数与人工标注掩膜、当前单元），以便下次继续编辑。
- **FR-7.3** 可载入工程文件，完整还原编辑状态（可复现）。
- **FR-7.4** 提示未保存的修改，避免误关丢失。

### FR-8 设置
- **FR-8.1** 算法参数（SAT/VAT 窗口、肌肉窗口、皮下带厚度、圆盘半径等，见附录 A）。
- **FR-8.2** 默认输出目录、默认颜色方案。
- **FR-8.3** 参数可恢复默认值。

## 8. 关键交互流程

1. **导入** → 列表出现病例 → 点击某例进入显示。
2. **自动分割** → 显示三层叠加 + 面积数值。
3. **微调**：例如 SMA 某处偏多 → 选"擦除笔"在 SMA 层涂掉；某处漏了 → 选"区域生长"在肌肉上点种子（HU 上限/下限调好）→ 生长结果"加入 SMA" → 面积实时更新。
4. **核对**：切换"只看 SMA""半透明"等视图确认边界。
5. **导出**：导出该例 CSV/PNG；或切到批量导出全部。
6. **保存工程**（可选）。

## 9. 算法说明（v3 阈值几何法）

> 参考实现：`_threshold_v3.py`（零依赖 pydicom/numpy/scipy）。

**输入**：单层 CT 像素 → HU 换算（`slope×pixel + intercept`）、`PixelSpacing`。

1. **身体掩膜**：`HU > −350` → 填洞 → 开运算 → 腐蚀，得到体部区域。
2. **离体表距离**：由体部外轮廓做距离变换，得每点到体表的距离。
3. **皮下脂肪 SAT**：脂肪窗（−190~−30）内、从体表沿脂肪做**测地膨胀**（默认 22mm），抗脂肪环断裂。
4. **内脏脂肪 VAT**：其余脂肪（与体表不相连/超出测地距离）。
5. **骨骼肌 SMA**：
   - **腹壁肌**：紧贴皮下脂肪内侧约 12mm 的软组织；
   - **脊柱两侧肌肉（腰大肌/椎旁肌）**：以最大骨块（椎体）为中心，从其沿软组织**洪水填充**（脂肪自动截断边缘），**生长过程排除正前 ±50° 扇形**（避开主动脉/肠管），最后以**圆盘半径 24mm** 封顶；
   - **排除**：肾等不贴骨结构（到骨距离约束）、脊髓/椎体骨髓腔（骨填洞后扣除）。
6. **面积**：各层像素数 × 像素面积。

**已知局限**（需在软件中提示用户人工复核）：
- 脏器与肌肉 HU 高度重叠，边缘仍可能需人工修正；
- 胸部层面切片谈"腹部骨骼肌/内脏脂肪"语义不严谨；
- 肌间脂肪未单列，暂并入 VAT。
