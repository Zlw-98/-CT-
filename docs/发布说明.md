## 1. 下载与启动

- 产物目录：`dist/腹部CT体成分分析工具/`
- **运行**：双击其中的 **`腹部CT体成分分析工具.exe`**（首次启动约数秒）。
- 整个文件夹可拷到任意 Windows 电脑（**无需安装 Python**），保持文件夹结构完整即可。
- 全程**离线**运行，不上传任何数据。

> 建议：把整个 `腹部CT体成分分析工具` 文件夹拷贝到目标机器，可直接双击 exe；如需桌面快捷方式，右键 exe → 发送到 → 桌面快捷方式。

## 2. 系统要求

- Windows 10 / 11（64 位）。
- 无需独立显卡即可运行（算法为 CPU 上的阈值几何法）。

## 3. 功能一览

- **导入**：DICOM 文件夹（递归）或单个 DICOM 文件；支持 GE/Siemens/Philips/联影。
- **自动分割**：一键（F5）或批量（F6）v3 阈值几何法，自动画出 **皮下脂肪 SAT / 内脏脂肪 VAT / 骨骼肌 SMA**。
- **人工微调**：区域生长、画笔/橡皮（可按 **HU 范围限制**、可选 **软边** 羽化）、撤销/重做（Ctrl+Z / Ctrl+Y）。
- **实时面积**：右侧面板实时显示各层面积（cm²）及总脂肪、VAT/SAT、肌肉平均 HU、身体面积；区分「自动结果 / 已人工微调」，支持「重置为自动结果」。
- **视图辅助**：图层显示/隐藏、透明度、锁定、清空；只看某层；半透明叠加；**只看叠加（隐藏 CT）**。
- **导出**：CSV（UTF-8-BOM，Excel 中文不乱码）+ 叠加分割图 PNG（含颜色图例与面积）。
- **工程文件**：保存/载入 `.bcprj`，完整还原标注（可复现）；未保存时关闭会提示。
- **设置**：v3 算法参数、默认输出目录、图层颜色，可恢复默认（持久化到 `%APPDATA%`）。

## 4. 已知限制

- 本期面向**孤立单层轴位切片**，只计算**横截面积（cm²）**，**不计算体积（cm³）**。体积需补全完整腹部序列（层厚 ≤2mm，膈顶至耻骨联合）。
- 自动分割为 v3 阈值几何法，脏器/肌肉 HU 重叠处需人工微调（界面提供微调闭环与「已编辑」标记）。
- 导出本期仅 CSV + 叠加 PNG，不含 xlsx / NRRD。

## 5. 从源码打包（可选）

1. 安装 PyInstaller：`pip install pyinstaller`
2. 运行 `打包.bat`（或 `pyinstaller --noconfirm build.spec`）
3. 产物输出到 `dist/腹部CT体成分分析工具/`

打包配置见 `build.spec`（onedir；`assets/` 随包；`console=False`）。
